# My OpenClaw Skills 🦞

个人 OpenClaw 技能库，可在任意设备上复用。

## 📦 技能列表

| 技能 | 描述 |
|------|------|
| [csdn-blog-publisher](./csdn-blog-publisher/) | 撰写并发布技术博客到 CSDN |

## 🚀 使用方法

### 方式一：直接复制到 OpenClaw skills 目录

```bash
# 克隆仓库
git clone https://github.com/jx1100370217/my-openclaw-skills.git

# 复制技能到 OpenClaw
cp -r my-openclaw-skills/csdn-blog-publisher ~/.openclaw/skills/
# 或
cp -r my-openclaw-skills/csdn-blog-publisher /path/to/openclaw/skills/
```

### 方式二：软链接

```bash
ln -s /path/to/my-openclaw-skills/csdn-blog-publisher ~/.openclaw/skills/csdn-blog-publisher
```

## 📝 技能说明

### csdn-blog-publisher

自动化 CSDN 博客发布流程：
- 📚 内容研究与资料收集
- ✍️ 符合 CSDN 规范的博客撰写
- 🖼️ 免费封面图获取
- 🌐 浏览器自动化发布

**触发示例：**
- "帮我写一篇关于 AI Agent 的博客发到 CSDN"
- "发布一篇技术文章到 CSDN"
