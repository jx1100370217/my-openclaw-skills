# App Store Optimization Checklist

## Pre-Launch ASO

### Keyword Research
- [ ] Identify 20-30 relevant keywords
- [ ] Analyze competitor keywords
- [ ] Check keyword difficulty/volume
- [ ] Prioritize by relevance and competition
- [ ] Include long-tail variations

### App Name (30 chars)
- [ ] Primary keyword included
- [ ] Brand name if space allows
- [ ] Readable and memorable
- [ ] No keyword stuffing

### Subtitle (30 chars)
- [ ] Secondary keyword included
- [ ] Complements title (no repetition)
- [ ] Describes key benefit

### Keywords Field (100 chars)
- [ ] No spaces after commas
- [ ] No duplicates from title/subtitle
- [ ] Mix of branded and generic terms
- [ ] Singular forms preferred
- [ ] All 100 characters used

### Description (4000 chars)
- [ ] Hook in first 3 lines (visible by default)
- [ ] Keywords naturally integrated
- [ ] Features with benefits listed
- [ ] Social proof included
- [ ] Clear call-to-action
- [ ] Localized for target markets

## Visual Assets

### App Icon
- [ ] Recognizable at small sizes
- [ ] Consistent with app design
- [ ] No text (unless brand)
- [ ] Stands out from competitors
- [ ] A/B tested if possible

### Screenshots (First 3 Critical)
- [ ] Show core features
- [ ] Text captions added
- [ ] Consistent visual style
- [ ] High contrast, readable
- [ ] Localized text for each market

### App Preview Video
- [ ] Shows real app usage
- [ ] First 3 seconds compelling
- [ ] Captions for sound-off viewing
- [ ] 15-30 seconds length
- [ ] Portrait orientation for iPhones

## Rating & Reviews Strategy

### Getting Reviews
- [ ] In-app review prompt (SKStoreReviewController)
- [ ] Triggered after positive moment
- [ ] Max 3 prompts per 365 days
- [ ] Respect user's no-review choice

### Responding to Reviews
- [ ] Reply to negative reviews (fix + apology)
- [ ] Thank positive reviewers
- [ ] Update when issues are fixed
- [ ] Professional, empathetic tone

## Monitoring Metrics

### Key Performance Indicators
| Metric | Target | Tool |
|--------|--------|------|
| Impressions | ↑ Monthly | App Analytics |
| Conversion Rate | > 30% | App Analytics |
| Keyword Rankings | Top 10 | ASO Tool |
| Rating | > 4.5 | App Store Connect |
| Retention D1 | > 40% | Analytics |

### Weekly Tasks
- [ ] Check keyword rankings
- [ ] Respond to new reviews
- [ ] Monitor competitor updates
- [ ] Analyze conversion changes

### Monthly Tasks
- [ ] Review ASO strategy
- [ ] Update screenshots if needed
- [ ] Refresh promotional text
- [ ] Analyze feature request trends

## A/B Testing (Search Ads)

### What to Test
1. Screenshots order and design
2. App icon variations
3. Preview video vs. screenshots
4. Different value propositions

### Test Parameters
- Run for 7-14 days minimum
- Statistical significance > 95%
- Test one element at a time
- Document all results

## Common ASO Mistakes

1. ❌ Keyword stuffing in title
2. ❌ Spaces in keywords field
3. ❌ Screenshots showing onboarding
4. ❌ Ignoring negative reviews
5. ❌ Not localizing for key markets
6. ❌ Inconsistent visual branding
7. ❌ Forgetting to update for new iOS features
